# Bangladesh Travel Guide（日本企業向けポートフォリオ版）

バングラデシュの都市・自然・食文化を、日本語で分かりやすく紹介する静的Webサイトです。
日本企業へのポートフォリオ提出を想定し、文章、デザイン、ページ構成、操作性を統一しました。

## 主な改善内容

- 日本語表現を自然で読みやすい文章に修正
- 英語と日本語が不規則に混在していた見出しを整理
- 全ページのヘッダー、フッター、配色、余白を統一
- スマートフォン、タブレット、PCに対応
- 壊れていた画像パスを修正
- 画像をWebP形式に最適化し、ファイル容量を削減
- モバイルメニュー、タブ、カルーセル、ライトボックスをJavaScriptで実装
- キーボード操作、フォーカス表示、スキップリンクなどのアクセシビリティに配慮
- 「制作概要」を追加し、企業担当者が技術面を確認しやすい構成に変更
- 学習用デモサイトであることと、旅行情報の確認に関する注意書きを追加

## ページ構成

- `index.html`：トップページ
- `dhaka.html`：ダッカ紹介
- `coxs-bazar.html`：コックスバザール紹介
- `sundarbans.html`：スンダルバンス紹介
- `bandarban.html`：バンダルバン紹介
- `gallery.html`：写真ギャラリー

## 使用技術

- HTML5
- CSS3
- JavaScript（Vanilla JS）
- Responsive Web Design
- WebP画像最適化

## 確認方法

1. フォルダーを展開します。
2. `index.html` をブラウザーで開きます。
3. 地図を表示する場合はインターネット接続が必要です。

ローカルサーバーを使用する場合：

```bash
python -m http.server 8000
```

その後、ブラウザーで `http://localhost:8000/` を開きます。
