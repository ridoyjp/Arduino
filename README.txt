# RIDОY Portfolio

A responsive personal portfolio built with:
- HTML5
- CSS3
- Vanilla JavaScript

## Sections
HOME → ABOUT → SKILLS → PROJECTS → TEAM DEVELOPMENT → EXPERIENCE → STRENGTHS / 自己PR → FUTURE / 今後の目標 → GITHUB → CONTACT

## Run
Open `index.html` in a browser.

## Customize
- Replace the GitHub URL in `index.html`.
- Replace the email address in `script.js`.
- Add project screenshots/images if desired.
